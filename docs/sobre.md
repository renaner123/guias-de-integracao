# Sobre o acervo

Este é o caderno público de integrações de **Renan Rodolfo Dev**.
Os guias nascem de implementações reais: registram não só a configuração ideal,
mas também os erros encontrados e o caminho para diagnosticá-los.

## Como usar

- Confira a data do artigo e as referências oficiais.
- Substitua os identificadores de exemplo pelos seus.
- Mantenha segredos fora do Git e do código do aplicativo.
- Teste em homologação antes de disponibilizar pagamentos aos usuários.

Menus, permissões e comandos mudam. Um teste de conexão bem-sucedido não substitui
a validação da integração completa no seu projeto.

## Correções e sugestões

Encontrou uma etapa diferente? [Abra uma issue no GitHub](https://github.com/renaner123/guias-de-integracao/issues)
ou use o link de edição no final da página. Nunca inclua tokens, senhas, chaves
privadas ou dados pessoais nas contribuições.
